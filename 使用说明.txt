个人API调用对话系统  V1.0.1
================================================

一、启动
  双击 PACC-V1.0.exe（不要单独拷走 exe，它依赖同目录 _internal）

二、第一次启动
  选择模型 → 填入该服务的 API Key → 设置本地密码
  Key 加密保存到 config.enc，之后每次启动输入密码即可

三、关闭启动密码
  菜单 → 设置 → 启动密码 → 不需要
  之后启动直接进入；再切回「需要」会要求设置新密码
  注意：关闭后本机任何人都能直接使用已保存的 Key

四、界面
  侧栏「当前模型」卡片：切换模型（品牌徽标 + 型号，按首字母排序）
  左上角 ☰：设置 / 模型 / 导出
  右上角 ?：使用教程    i：关于
  输入区：深度思考、智能搜索、📎 附件
  输入区上方：本次对话 token 用量与折算费用
  每条回答下方：复制 / 重新生成

五、推理过程
  设置开启「推理过程」后，生成中实时显示推理内容，
  完成后折叠为「▼ 已深度思考（用时 X 秒）」，点击展开

六、数据文件（exe 同目录）
  chat_history.json  对话记录
  config.enc         加密的 API Key 库
  settings.json      字号、打字速度、发送方式、推理过程、启动密码
  debug.log          运行日志

七、已知限制
  附件：文本并入消息，图片只记录文件名
  智能搜索走 DuckDuckGo，可能被限流
  推理可视化依赖服务商返回 reasoning_content
  余额查询仅 DeepSeek 可用
  生成回答时不能切换模型
  复杂公式（矩阵、含中文结构）会自动降级为 Unicode

八、系统要求
  Windows 10/11 64 位，纯绿色便携，不写注册表
