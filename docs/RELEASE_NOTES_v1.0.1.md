# V1.0.1

> 本次是 αpiv0004 系列的正式汇总版本，重点提升**稳定性、模型隔离与生成交互体验**。
> 如果你从 V1.0 升级：直接替换整个文件夹即可，`chat_history.json` / `config.enc` / `settings.json` 完全兼容。

---

## ✨ 主要更新

### 模型与推理
- **推理强度可调**：支持的模型（Qwen3 / GLM-4.6 / 豆包）在**输入栏下方**直接切换档位，无需进设置
- **真实图片输入**：7 个视觉模型（GPT-4o / 4o-mini / Gemini-2.0-Flash / Claude-Sonnet-4 / Grok-4 / 豆包-Seed-1.6 / ERNIE-4.5）可直接读图
- **上下文进度徽标**：只统计当前对话，超过 50% 变琥珀、75% 变红并自动压缩历史

### 对话与历史
- **历史按模型隔离**：侧栏只显示当前模型的对话，每条显示模型名
- **「更多记录」长条**：列表底部浮出，用于查看其他模型的对话（**只读**，避免误改）
- **停止生成更像 DeepSeek**：直接断开调用，已生成内容保留；随后可「重新生成」或「编辑这条提问」
- **精确交互**：「重新生成 / 编辑提问 / 展开思考」三个入口按字符区间命中，点文字才算，点空白不再误触

### 界面
- 设置页改用**圆角胶囊**分段控件
- 使用教程精简为 4 章，改为**圆角卡片**
- 关于页新增**项目主页**链接，版本号 / 已知问题同步

---

## 🐞 修复

- 未开启深度思考时仍显示推理过程与「已深度思考」标题
- 切换模型后新建对话，旧模型对话被错误归到当前模型
- 查看其他模型对话时可直接发送，导致记录被改写（现为只读）
- 停止生成时弹出「Connection error.」错误框
- 停止后无法重新生成（停止标记未清理导致每次立即中断）
- 停止后无法修改原问题（现两个入口都会出现）
- 失败提示块重复堆叠
- 切换模型后聊天气泡里的模型名不同步
- 生成过程中文本重复膨胀
- 跨行 `$$...$$` 公式被拆散、`\rightarrow` 前缀被误删
- 灰度模型图标四角出现黑块

## ⚠️ 已知问题

完整清单见 README「已知问题」，主要有：

- 单文件版在部分受限环境可能解包失败，请用目录版
- 矩阵 / cases / 含中文结构的公式会降级为 Unicode 文本
- 服务商不返回 `usage` 时，token 与费用为估算值
- 推理强度仅 Qwen3 / GLM-4.6 / 豆包可调
- 图片超过 4MB 会被跳过；PDF / Office 文件暂不支持解析
- 生成回答期间不能切换模型
