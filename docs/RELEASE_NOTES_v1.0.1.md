# V1.0.1

本次为 αpiv0004 系列的正式汇总版本，主要提升**稳定性、模型隔离与生成流畅度**。

## 亮点

- **推理强度可调**：支持的模型（Qwen3 / GLM-4.6 / 豆包）在输入栏下方直接切换档位
- **真实图片输入**：7 个视觉模型可直接读图，不再只是记录文件名
- **上下文进度徽标**：只统计当前对话，接近上限自动压缩并提示
- **历史按模型隔离**：侧栏只显示当前模型的对话，条目显示模型名；底部「更多记录」可查看其他模型，且为只读
- **停止生成更实用**：直接断开调用，保留已生成内容，可「重新生成」或「编辑这条提问」
- **界面圆角化**：设置页改为圆角胶囊控件，使用教程改为圆角卡片并精简

## 修复

- 未开启深度思考仍显示推理过程与「已深度思考」标题
- 切换模型后新建对话串到其他模型
- 查看其他模型对话可直接发送导致记录被改写
- 生成过程中文本重复膨胀
- 跨行公式被拆散、箭头前缀被误删
- 灰度图标四角黑块
