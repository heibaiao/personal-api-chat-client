# V1.0

首个公开版本：单文件 Tkinter 桌面 AI 对话客户端。

## 亮点

- **37 个模型 / 32 个品牌**，全部走 OpenAI 兼容接口，每个模型独立保存 API Key
- **品牌徽标列表**：已导入彩色、未导入灰度，按首字母排序
- **实时渲染**：生成过程中按行渲染 Markdown（标题 / 列表 / 代码块 / 加粗）
- **公式与化学式**：matplotlib 排版图优先，失败自动降级 Unicode
- **推理可视化**：生成中实时显示，完成后折叠为「▼ 已深度思考（用时 X 秒）」
- **对话级用量计费**：输入/输出 tokens + 按官方单价折算费用，K/M 单位
- **加密存储**：PBKDF2-HMAC-SHA256（20 万次）+ HMAC 认证流；启动密码可在设置中关闭
- 深色 UI、内置使用教程、导出 TXT、DeepSeek 余额查询

## 安装

1. 下载 `PersonalAPIChatClient-V1.0-portable-win64.zip`
2. 解压，双击 `PACC-V1.0.exe`
3. 首次启动：选模型 → 填 API Key → 设本地密码
